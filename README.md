# Research Lab Website Starter

A standalone, responsive HTML/CSS/JS starter inspired by the organization and academic content sections of [Greene Lab Website Template](https://github.com/greenelab/lab-website-template) and [Houlahan Lab](https://github.com/houlahanlab/houlahanlab.github.io). This is **not** a fork or Jekyll implementation of those projects.

## Customize
- Edit `index.html` to change the lab name, research, team, publications, news, contact email and project descriptions.
- Edit `style.css` to customize colors and typography.
- The publications and team members are fictional placeholders; do not publish as real lab records.

## Publish with GitHub Pages
1. Create a public GitHub repository (e.g. `yourusername.github.io`).
2. Upload `index.html`, `style.css`, and `script.js` to its root.
3. Go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Open `https://yourusername.github.io/` once GitHub Pages finishes deploying.

## Original templates
For the complete Jekyll workflow with automatic publication citations, member collections and blog features, use the Greene Lab repository's **Use this template** option instead. This lightweight starter has static sections only.
